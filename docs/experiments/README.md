# 实验记录

这里放**手册第七章那个「一下午实验」**的产出。它是整条路上最重要的一步——
如果整份手册只做一件事，做这件。

## 一次实验应该留下三样东西

1. **3 张卡片**（截图或复制文本）——从生成的卡片里人工挑出「问到了点子上」的
2. **一份问答记录**——被 AI 扮演的答辩老师追问的全过程
3. **一个数字**——接住了几层（0–4）

这三样加在一起，就是「我的产品解决了一个真实问题」的**唯一硬证据**，
比十页设计文档都管用。

## 文件命名

```
docs/experiments/
├─ TEMPLATE.md                          ← 记录模板，复制它
├─ 2026-10-14-实验01-登录模块.md
└─ 2026-10-15-实验02-数据处理.md
```

## 三种结果的解读（手册 §7.4）

| 结果 | 说明什么 | 下一步 |
|---|---|---|
| 0–1 层 | 卡片没写到点子上，或问题问得太浅。**不是你的问题，是产品的问题** | 改进提示词，强制卡片必须包含「替代方案」和「代价」，再跑一次 |
| 2 层 | **最有价值的结果。** 恰好证明「看了解释 ≠ 掌握」 | 原样保留，它就是答辩里最有说服力的一张图 |
| 3–4 层 | 方法有效，或这个项目你本来就熟 | 换一个更生的项目再测一次 |

## 明确不要记的指标

展开解释次数、点击选择次数、卡片阅读时长。**这些数字好看，什么都不能证明。**
唯一算数的是：数天后，你还改不改得动。
